# 作用域与栈内存

本部分重点探讨 Rust 引用在最基础维度下的安全机制——**基于作用域与局部栈帧的生命周期分析**。

在 Rust 的内存安全模型中，所有的变量都与其声明时的词法作用域紧密相连。为了理解借用检查器（Borrow Checker）是如何在编译期静态地阻止悬空指针与双重释放等致命 Bug，我们将从以下几个关键维度展开深度剖析：

1. **变量作用域分析（Variables Scope Analysis）**：探讨变量在源代码中的词法可见性（Visibility）与实际存活区间（Liveness）的映射关系。
2. **栈帧生命周期（Stack Frame Lifetimes）**：从计算机系统底层的视角，分析当函数调用栈发生入栈（Push）和出栈（Pop）时，局部变量的内存地址是如何分配、重用以及失效的。
3. **析构顺序（Destructors Ordering / Drop Order）**：解析 Rust 在离开作用域时如何按照严格的相反顺序（FILO - 先进后出）自动调用 `Drop` 析构函数，以及这种顺序如何从根本上确保了引用与所有权的安全边界。

通过本章的学习，您将构建起坚实的“生命周期内存物理布局”心智模型，并能够从编译器和底层的角度，洞悉引用背后的物理本质。
