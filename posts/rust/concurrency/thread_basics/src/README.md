# 前言：Rust 多线程并发基石

在现代软件工程中，随着多核处理器的普及，并发编程（Concurrency）已成为榨干硬件性能的必备手段。然而，传统的并发模型（如基于共享内存与锁的并发）往往伴随着“数据竞争”（Data Race）、“死锁”（Deadlock）、“内存悬垂”（Dangling Pointers）等极其隐蔽且难以调试的 Bug。

Rust 语言通过其革命性的**所有权模型（Ownership）**、**生命周期系统（Lifetimes）**以及**类型系统（Type System）**，在编译期将绝大多数并发安全隐患斩于马下。这种设计哲学被称为**“无畏并发”（Fearless Concurrency）**。Rust 允许开发者编写出既能充分压榨多核硬件性能，又具备强内存安全保证的并发程序。

本书将带你深入 Rust 多线程并发底层的核心原理，从操作系统的线程模型出发，逐步剖析 Rust 独特的线程生存期管理、类型系统的安全特质（`Send` / `Sync`）、以及基于消息传递的通道（Channel）机制。

## 本书内容概览

为了系统且深入地剖析 Rust 并发编程的基石，本书分为以下三个核心章节：

### 1. [操作系统线程管理与生存期](01_thread_management.md)
我们将探讨 Rust 线程与操作系统原生内核线程的 1:1 映射关系，并分析线程创建的开销与资源限制。紧接着，我们将深入研究线程的生存期管理，包括：
* `std::thread::spawn` 的使用方法及局限性。
* 为什么 `spawn` 必须满足 `'static` 生命周期限制，以及这如何防止悬垂指针。
* Rust 1.63 引入的 **Scoped Threads（作用域线程）** 机制如何打破 `'static` 限制，实现在线程中安全地借用父上下文的局部变量。
* 线程的优先级、栈大小配置（通过 `Builder`），以及异常传播机制（Panics in threads）。

### 2. [Send 与 Sync 特质的内存安全边界](02_send_sync_safety.md)
这是理解 Rust “无畏并发”最关键的理论基础。我们将深入到编译器内部，解析这两个特殊的标记特质（Marker Traits）：
* **`Send` 的本质**：所有权在线程间转移的安全性。
* **`Sync` 的本质**：多个线程通过共享引用（`&T`）并发访问相同数据的安全性。
* `Send` 与 `Sync` 的推导规则、它们与原生指针 `*mut T` / `*const T` 的关系。
* 剖析经典非 `Send` 或非 `Sync` 的类型（如 `Rc<T>`、`RefCell<T>`、`Cell<T>`）背后的内存布局与安全隐患，并推导为何它们在多线程环境下会引发未定义行为（Undefined Behavior）。
* 讲解如何通过 `Arc<T>` 与 `Mutex<T>` 的组合构建线程安全的共享数据容器。

### 3. [mpsc 通道通信与消息传递](03_channel_communication.md)
遵循 Go 语言著名的“不要通过共享内存来通信，而要通过通信来共享内存”的哲学，我们将系统探讨 Rust 标准库中提供的 `std::sync::mpsc` 通道：
* **异步通道（Asynchronous Channel）** 与 **同步通道（Synchronous / Bounded Channel）** 在底层数据结构、缓冲区设计、以及阻塞/非阻塞行为上的本质区别。
* `Sender`（多生产者）与 `Receiver`（单消费者）的生命周期与内存结构。
* 如何使用 `mpsc` 实现优雅的线程协同与数据分发。
* 分析通道底层的内存释放顺序，以及发送端全部丢弃后接收端如何自动终止等机制。

## 学习目标

完成本书的学习后，你将能够：

1. **掌握 Rust 的 1:1 线程模型**：熟练地使用原生线程及 `scoped` 线程处理不同的并发任务，明白何时应该使用何种线程模型，避免不必要的内存拷贝。
2. **深入理解内存安全边界**：在面对编译器给出的 `Send` / `Sync` 报错时，能准确判断其底层的内存安全隐患，并熟练运用 `Arc`、`Mutex` 或 `RwLock` 予以解决。
3. **构建健壮的消息传递系统**：掌握标准库通道的内部运行机制与背后的缓冲区限制，能为高并发服务设计合适的生产者-消费者架构，避免因死锁或内存泄露导致的服务崩溃。
4. **具备生产级代码编写能力**：通过书中提供的高质量、带详细注释的 Rust 示例代码，能够直接编写出高可靠性、高性能的多线程系统软件。

让我们正式开启 Rust 多线程并发的深度探索之旅！
