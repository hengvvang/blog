# 第一部分：声明语法与内存布局

在深入掌握 C 语言高级指针操作之前，我们必须首先跨越语法解析的关卡，并在物理内存层面理解指针与数组的底层映射机制。C 语言的声明方式由于秉承了“声明与使用一致”的历史设计哲学，在面对复杂复合类型时可能会显得晦涩难懂。

本部分将系统性地拆解声明语法，并重点介绍以下核心内容：

1.  **运算符优先级与结合性：** 理解为什么 `[]` 和 `()` 的优先级高于 `*`，以及这一规则如何直接决定了变量的底层类型本质。
2.  **左右法则（螺旋法则）：** 提供一种结构化、算法化的步骤来逆向解析任何复杂的 C 语言类型声明，确保你不会在“指针的数组”和“指向数组的指针”之间产生混淆。
3.  **字节级物理内存布局：** 通过直观的内存地址图景，解析指针数组与数组指针在栈或全局数据区所占用的真实字节大小（尤其在 64 位与 32 位系统环境下的区别），以及它们的空间连续性差异。
4.  **编译器类型系统：** 从静态分析和编译期类型检查的角度，探讨为什么不能将数组指针混淆为普通的二级指针（`T**`），并剖析这种行为在底层硬件层面的破坏性。

通过本章的学习，你将在脑海中建立起严谨的物理内存模型，为后续理解指针算术偏移与多维数组衰变奠定坚实的技术基石。
