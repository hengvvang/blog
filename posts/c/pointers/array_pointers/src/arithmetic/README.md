# 第二部分：指针算术与解引用原理

在建立了静态声明与内存布局的模型后，我们必须深入探讨它们在程序运行时的动态行为。指针的强大底层控制力很大程度上来源于其算术运算（Pointer Arithmetic）与解引用操作（Dereferencing）。

本部分将系统性地拆解指针运行时的运算机制，重点涵盖以下方向：

1.  **指针算术偏移公式：** 深入探讨 `ptr + n` 的字节级计算公式，详细解析为什么指针加法偏移的物理地址大小与其指向的基类型大小密切相关。
2.  **解引用优先级的求值路径：** 拆解 `*pa[i]` 与 `(*ap)[i]` 在编译期生成的不同求值顺序，厘清括号在此类复合表达式中的关键阻断作用。
3.  **多维数组退化/衰变机制（Decay）：** 深度揭秘为什么二维数组名在大多数表达式中会被自动转换为指向首行数组的数组指针（`T(*)[N]`），并详细推导多维数组寻址的等价链条。

掌握了本部分的运行时规律后，你将能够准确预测和计算每一次指针移动的绝对字节偏移，彻底消除多维空间寻址中的盲目性与越界隐患。
