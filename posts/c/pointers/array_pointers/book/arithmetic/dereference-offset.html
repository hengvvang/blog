Array Pointers & Pointer Arrays

第二章：解引用与指针算术偏移

在掌握了复杂的声明语法和物理布局之后，我们必须深入探讨它们在运行时的表现。指针的核心威力在于解引用（Dereferencing）与算术运算（Pointer Arithmetic）。

本章将详细剖析多级解引用的求值路径、地址偏移的字节计算逻辑，以及多维数组如何衰变（Decay）为数组指针。

1. 多级解引用机制与优先级约束

解引用操作符 * 与下标操作符 [] 在求值时有不同的语义。我们需要厘清它们在指针数组与数组指针上的执行路径。

1.1 指针数组 int *pa[N] 的解引用

由于 pa 本身是一个数组，它的元素是 int*（指针类型）：

  • 访问指针本身： pa[i] 直接取出第 $i$ 个槽位里存储的地址。
  • 访问目标数值： *pa[i] 对第 $i$ 个槽位里的地址进行解引用，获取其指向的 int 变量。
  • 优先级细节： 这里的 *pa[i] 相当于 *(pa[i])，因为下标操作符 [] 的优先级高于解引用操作符 *。
  • 二级指针等价性： 表达式 *(pa + i) 等价于 pa[i]。因此，当我们要访问第 $i$ 个指针指向的值时，写成 **(pa + i) 与 *pa[i] 是完全等价的。特别地，首个元素指向的值即为 **pa。

1.2 数组指针 int (*ap)[N] 的解引用

ap 本身是一个指针，指向一整行含有 $N$ 个元素的数组：

  • 一级解引用： *ap。
    • 在类型系统层面，对一个指向数组的指针进行一级解引用，其得到的值类型是“具有 $N$ 个元素的一维数组 int[N]”。
    • 关键物理事实： 尽管 ap（类型为 int(*)[N]）和 *ap（类型为 int[N]）在表达的“对象类型”上完全不同，但是它们所存储的地址数值在字节级别是完全相同的，都指向当前行的起始地址。
  • 降维衰变（Decay）： 得到的这个一维数组 *ap 在参与绝大多数表达式运算时，会立即发生退化，退化为指向其第一个元素的指针，即 int* 类型。
  • 二级解引用与元素访问： (*ap)[j]。
    • 由于 [] 优先级高于 *，必须使用括号 (*ap) 强制先解引用，得到一维数组本体，然后再使用 [j] 访问数组的第 $j$ 个元素。
    • 如果不加括号写成 *ap[j]，则等价于 *(ap[j])。由于 ap[j] 被解释为 *(ap + j)，程序会在地址上直接偏移 $j$ 行（即 $j \times N \times \text{sizeof}(int)$ 字节），然后解引用。这几乎一定不是你的本意。
    • 等价的指针式写法： *(*ap + j)。一级解引用 *ap 衰变为 int*，此时对其加 $j$ 表示在行内偏移 $j$ 个 int 的距离，最后进行第二次解引用获取数值。

2. 指针算术与物理地址偏移机制

C 语言中指针加减法（ptr + n）的物理寻址公式遵循如下通用数学规律：

$$\text{Address}{\text{new}} = \text{Address}{\text{old}} + n \times \text{sizeof}(*\text{ptr})$$

这个公式的核心在于：指针每移动一个单位，其实际物理地址移动的字节数等于该指针指向的基类型（Dereferenced Type）的大小。

2.2 偏移计算案例推演

实例 A：pa + 1

  • pa 的类型是 int *[4]。在进行算术运算时，它会退化为指向首元素的指针，类型为 int **。
  • 它的基类型是 int *。
  • 根据偏移公式：$\text{sizeof}(\text{pa}) = \text{sizeof}(int) = 8$ 字节。
  • 因此，pa + 1 物理地址前移 8 字节。

实例 B：ap + 1

  • ap 的类型是 int (*)[4]。它本身就是一个指针。
  • 它的基类型是包含 4 个整数的数组 int[4]。
  • 根据偏移公式：$\text{sizeof}(*\text{ap}) = \text{sizeof}(int[4]) = 4 \times 4 = 16$ 字节。
  • 因此，ap + 1 物理地址前移 16 字节，直接跳过了当前整行。

实例 C：*ap + 1

  • *ap 的类型是 int[4]。在计算时它发生退化，转换为指向首个元素的普通指针 int *。
  • 它的基类型是 int。
  • 根据偏移公式：$\text{sizeof}(**\text{ap}) = \text{sizeof}(int) = 4$ 字节。
  • 因此，*ap + 1 物理地址前移 4 字节，实现了在同一行内向右移动一个整型单元。

3. 多维数组的指针衰变（Decay）

在 C 语言中，二维数组 int matrix[3][4] 在物理上其实也是一块连续的一维字节块（共计 $3 \times 4 \times 4 = 48$ 字节）。然而，在编译期类型系统中，它被赋予了多维属性。

3.1 衰变机制图示

二维数组 matrix[3][4] 在表达式中的类型衰变退化链：

matrix (二维数组名，类型 int[3][4])
  │
  ├─► 在大多数表达式中发生类型退化 (Decay)
  ▼
指向其首个元素（即第一行一维数组）的指针，类型为 int (*)[4]
  │
  ├─► 允许直接通过赋值承接：int (*ap)[4] = matrix;
  ▼
当访问元素 matrix[i][j] 时，编译器通过嵌套求值生成寻址路径：

          matrix + i        <-- 跨越 i 行，偏移字节数 = i * (4 * sizeof(int)) = i * 16 字节
              │
              ▼ 解引用 (*)
          *(matrix + i)     <-- 类型退化，转换为 int* 类型，代表第 i 行首元素的地址值
              │
              ▼ 加上元素偏量 j
         *(matrix + i) + j  <-- 跨越 j 个整型元素，偏移字节数 = j * sizeof(int) = j * 4 字节
              │
              ▼ 再次解引用 (*)
        *(*(matrix + i) + j) <-- 获取该物理内存槽位中的真实 int 整数

3.2 寻址等价链条

根据 C 标准关于下标运算符的定义：X[Y] 等价于 *(X + Y)。我们可以推导出二维数组寻址的经典等价逻辑链：

$$\text{matrix}[i][j] \iff ((matrix + i) + j) \iff \text{ap}[i][j] \iff ((ap + i) + j)$$

这一等价链条完美解释了为什么可以用数组指针以与二维数组完全一致的下标语法（ap[i][j]）来进行高效、直观的寻址操作。

4. 实验验证与代码实例

下面的完整程序使用 uintptr_t（无符号整型指针，定义在 <stdint.h>）直接打印和计算地址的绝对差值，以此证明上述的偏移规律。

#include <stdio.h>
#include <stdint.h>

int main(void) {
    // 准备一个 3 行 4 列的二维数组
    int matrix[3][4] = {
        {10, 11, 12, 13},
        {20, 21, 22, 23},
        {30, 31, 32, 33}
    };

    // matrix 衰变为指向第一行数组的指针，类型为 int (*)[4]
    int (*ap)[4] = matrix;

    // 准备一个指针数组，指向 matrix 的各个行
    int *pa[3] = { matrix[0], matrix[1], matrix[2] };

    printf("=== [1] 数组指针 ap 与二维数组名偏移对比 ===\n");
    printf("ap 的初始地址值          (Row 0): %p\n", (void*)ap);
    printf("ap + 1 的地址值          (Row 1): %p\n", (void*)(ap + 1));
    printf("ap + 2 的地址值          (Row 2): %p\n", (void*)(ap + 2));

    // 使用 uintptr_t 做绝对地址差值计算
    uintptr_t diff_ap = (uintptr_t)(ap + 1) - (uintptr_t)ap;
    printf("ap + 1 与 ap 的物理距离: %lu 字节 (等于 4 * sizeof(int))\n\n", (unsigned long)diff_ap);

    printf("=== [2] 数组指针内部偏移 (*ap) 对比 ===\n");
    printf("*ap 的初始地址值        (Element 0): %p\n", (void*)(*ap));
    printf("*ap + 1 的地址值        (Element 1): %p\n", (void*)(*ap + 1));

    uintptr_t diff_inner = (uintptr_t)(*ap + 1) - (uintptr_t)(*ap);
    printf("*ap + 1 与 *ap 的物理距离: %lu 字节 (等于 sizeof(int))\n\n", (unsigned long)diff_inner);

    printf("=== [3] 指针数组 pa 偏移对比 ===\n");
    printf("pa 数组首地址 (pa[0] 槽位): %p\n", (void*)pa);
    printf("pa + 1 地址   (pa[1] 槽位): %p\n", (void*)(pa + 1));

    uintptr_t diff_pa = (uintptr_t)(pa + 1) - (uintptr_t)pa;
    printf("pa + 1 与 pa 的物理距离: %lu 字节 (等于 sizeof(int*))\n\n", (unsigned long)diff_pa);

    printf("=== [4] 二维元素读取路径等价性验证 ===\n");
    // 对比 *(*(ap + 1) + 2) 与 ap[1][2]
    int val_by_index = ap[1][2];
    int val_by_ptr   = *(*(ap + 1) + 2);
    printf("ap[1][2]           = %d\n", val_by_index);
    printf("*(*(ap + 1) + 2)   = %d\n", val_by_ptr);
    printf("是否等价: %s\n", (val_by_index == val_by_ptr) ? "是" : "否");

    return 0;
}
