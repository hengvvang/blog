# 面向对象设计模式

面向对象编程（OOP）并不是某种特定语言（如 C++ 或 Java）的专利，而是一种**软件设计思想**。其核心理念是通过将状态（属性/数据）和行为（方法/函数）结合，来抽象和复现现实世界或复杂系统中的业务实体。

在没有原生 OOP 支持的 C 语言中，我们如何构建面向对象的程序结构？本部分将系统介绍这方面的实现技术。

## OOP 的三大要素及其 C 语言映射

1. **封装（Encapsulation）**
   * **概念**：将对象的内部状态和实现细节隐藏在实体内部，仅向外部提供受控的公共访问接口。
   * **C 语言实现**：使用**不透明指针（Opaque Pointers）**，又称 **Pimpl 模式**。通过在头文件中前置声明结构体，在 `.c` 文件中定义其具体字段，阻止外部代码直接修改私有状态。

2. **继承（Inheritance）**
   * **概念**：子类继承父类的属性和方法，实现代码重用和“Is-A”的关系。
   * **C 语言实现**：使用**结构体嵌套（Struct Nesting）**。将基类结构体作为子类结构体的第一个成员，从而保证子类和基类在内存起始地址上的完全重合，确保向上转型（Upcasting）的地址安全。

3. **多态（Polymorphism）**
   * **概念**：同一接口可以被不同的子类以不同的方式实现，在运行时根据对象的实际类型动态分派方法。
   * **C 语言实现**：手动设计**虚函数表（Virtual Table, vtable）**和**虚表指针（Virtual Pointer, vptr）**。在运行时通过间接跳转指令实现方法的动态绑定（Dynamic Binding）。
