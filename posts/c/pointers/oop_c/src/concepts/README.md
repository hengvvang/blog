# 函数指针基础与回调

在 C 语言的体系中，数据与函数是天生分离的。数据存放在栈（Stack）、堆（Heap）或静态数据区（.data/.bss），而可执行的机器指令则存放在代码段（.text）。

本部分将探讨如何打破“数据”与“行为”的鸿沟，使得函数能够作为变量在程序中传递、存储和动态调用。

## 核心概念概述

1. **函数指针（Function Pointers）**
   函数指针是一种特殊的指针变量，它存储的不是数据对象的内存地址，而是函数在代码段的入口地址。通过函数指针，我们可以在运行时动态地决定调用哪一个函数，从而极大地增强了程序的动态调度能力。

2. **调用机制（Calling Mechanisms）**
   * **直接调用（Direct Call）**：编译器在编译期就已经确定跳转的绝对地址或相对偏移量，直接生成跳转目标固定的指令（如 `call` 或 `B`）。
   * **间接调用（Indirect Call）**：在运行时通过读取寄存器或内存中的目标地址来决定跳转方向（如 `call rax` 或 `BLX r3`）。这是函数指针和虚函数派发在硬件层面的真实操作。

3. **回调模式（Callback Pattern）**
   回调是指一种软件设计模式。在该模式中，我们向一段可执行代码（如一个通用函数或库接口）传入另一个具体函数（回调函数）的地址，使得该代码在特定事件或时机被触发时，调用我们传入的具体函数。
   * **同步回调**：在同一个线程的当前调用栈中完成，回调函数在注册接口返回之前被执行。
   * **异步回调**：在未来的某个时刻、由另外的线程或硬件中断（ISR）触发执行，具有独立的生命周期。

4. **上下文变量（Context Variables）**
   因为 C 语言的函数是无状态的（Stateless），在回调机制中，我们需要通过 `void *userdata` 传递一个“上下文指针”，将函数调用与用户特有的数据状态绑定起来。这种模式可以完美模拟高级语言中的“闭包”或“对象方法”。
