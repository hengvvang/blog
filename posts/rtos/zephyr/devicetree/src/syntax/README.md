# 设备树语法概述

设备树（Devicetree, DT）是描述系统物理硬件拓扑结构的规范，在 Zephyr RTOS 中起到了硬件与软件逻辑解耦的桥梁作用。

本部分主要探讨设备树的声明语法、节点层次关系、地址空间翻译逻辑以及 Overlay 机制：

- **DTS 语法与节点层级**：介绍节点命名规范、节点标签（Label）、单元地址（Unit Address）以及常用键值属性（如 `compatible`、`reg`、`status`）。
- **节点继承与 Overlays**：解密 SoC 级 `.dtsi`、Board 级 `.dts` 和 Application 级 `.overlay` 文件的合并与重载机制。
- **硬件拓扑描述**：深入分析物理硬件引脚（如 GPIO 规格符、中断控制器属性）在 DTS 中的表示方法，并展示合并后的树状 AST 模型。

通过掌握设备树语法的底层逻辑，开发者可以清晰地为自定义电路板编写出严谨且高效的硬件描述文件。
