# 引言：嵌入式实时操作系统的底层基石

在现代嵌入式系统与物联网（IoT）产品开发中，实时操作系统（RTOS）已成为管理复杂业务逻辑、满足硬实时性（Hard Real-Time）要求、提高系统吞吐与稳定性的标准软件平台。为了在物理上仅有单核（或有限核心）的 CPU 上模拟出多个任务同时运行的“并发”假象，实时内核必须以极高的频率、极低的开销以及极高的确定性在不同的执行流之间进行切换。这一在微观上不断发生的调度与恢复过程，被称为**上下文切换（Context Switch）**。

对于专业的嵌入式系统工程师而言，仅仅停留在高层 API 接口（如创建任务、发送信号量、请求互斥锁）的使用层面是远远不够的。当系统面临以下棘手的工程挑战时：
*   **硬实时响应失败**：某些关键中断被不明原因地长时间屏蔽或延迟响应；
*   **偶发性 HardFault 崩溃**：系统在高负载运行数小时或数天后，突然触发硬件异常（如堆栈溢出、非法内存访问）；
*   **诡异的系统“假死”**：任务陷入互相等待，或者高优先级任务被低优先级任务无限期阻塞（优先级翻转）；
*   **复杂的寄存器状态调试**：在断点调试中，如何通过分析内存中的堆栈帧还原崩溃现场。

只有深入理解底层寄存器架构、处理器硬件中断流与软件调度流的深度协同、汇编级上下文恢复细节，才能进行精准的故障定位与极致的系统优化。

---

## 本书设计初衷与目标

本书旨在立足于 **ARM Cortex-M** 系列处理器架构，深度解析主流实时操作系统 **FreeRTOS** 的内核底座。我们将以处理器寄存器、汇编级上下文切换和内核同步机制为切入点，帮助读者构建起从**物理硅片硬件行为**到**高层 C 语言内核算法**的完整技术链路。

通过阅读本书，您将掌握：
1.  **Cortex-M 架构的底层核心设计**：包括双堆栈指针（MSP & PSP）的物理隔离逻辑、控制寄存器（CONTROL）的切换细节以及异常处理器的尾链机制。
2.  **堆栈帧（Stack Frame）物理布局**：彻底解析任务初始化时如何伪造堆栈、中断发生时硬件自动压栈（Auto-Stacking）与软件手动压栈（Manual-Stacking）的空间排布，尤其在带 FPU（浮点运算单元）环境下的 Lazy Stacking（懒惰压栈）技术。
3.  **PendSV 汇编级上下文切换实现**：逐行分析 `xPortPendSVHandler` 汇编源码，探查 CPU 寄存器如何在调度前后安全转移，以及内核如何通过 BASEPRI 寄存器在切换期间保护临界资源。
4.  **优先级翻转及其自愈算法**：深入分析优先级翻转的底层成因、数学模型，并通过 FreeRTOS 源码级拆解，剖析互斥锁（Mutex）中**优先级继承协议（Priority Inheritance Protocol）**的完整实现逻辑。

## 本书内容架构

为保证学习的系统性与由浅入深的学习曲线，本书被划分为三个核心部分：

### [第一部分：任务调度与堆栈布局](scheduling/README.md)
*   **[任务调度器与 TCB（引言）](scheduling/README.md)**：探讨 FreeRTOS 调度器与任务控制块（TCB）的逻辑关系，以及任务栈的分配与安全边界。
*   **[第一章：TCB 结构体与任务堆栈初始化](scheduling/tcb-stack-layout.md)**：深入剖析任务控制块（`tskTCB`）各核心成员的设计考量，详细推导 Cortex-M 在无/有 FPU 条件下的伪造初始栈帧逻辑。

### [第二部分：上下文切换底层实现](context/README.md)
*   **[上下文切换原理（引言）](context/README.md)**：阐述硬件异常、系统悬起（Pending）机制及 PendSV 中断在 Cortex-M 系统架构中的独特使命。
*   **[第二章：PendSV 异常与上下文切换汇编实现](context/pendsv-handler.md)**：逐行解剖 Cortex-M 汇编级 `xPortPendSVHandler`，从中断进入、现场保存、调度算法执行到现场恢复和异常退出，完整还原 CPU 运行轨迹。

### [第三部分：优先级反转与互斥锁](hazards/README.md)
*   **[优先级反转与防范（引言）](hazards/README.md)**：介绍硬实时约束下任务并发访问共享资源时可能面临的时间确定性失效，以及防御性的同步原语设计。
*   **[第三章：优先级反转成因与互斥锁优先级继承机制](hazards/priority-inversion-mutexes.md)**：多维度展现优先级翻转的时间线，深度剖析 FreeRTOS 的 `xTaskPriorityInherit` 和 `xTaskPriorityDisinherit` 源码，并提炼出生产环境下规避此类危害的最佳工程实践。

让我们从最基础的堆栈布局开始，层层剥离 RTOS 的神秘面纱。
