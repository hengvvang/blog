# 第一部分：ADC 多通道高速采样 - 引言

在嵌入式与信号处理系统中，将连续的模拟物理信号（如电流、电压、压力、温度等）高保真地转换为数字信号，是整个控制环路与计算任务的起点。如果输入端的采样数据不够精准或实时性不足，后续的数字信号处理（DSP）算法或闭环控制逻辑都将失去意义。

本部分将聚焦于 **STM32 微控制器的 ADC（模数转换器）多通道高速采样与信号预处理技术**，深入探讨如何从硬件底层与算法层面提升模拟信号的采集品质。

---

## 本部分核心主题

### 1. ADC 转换原理与逐次逼近型（SAR）架构
STM32 内部集成的 ADC 主要采用**逐次逼近型（Successive Approximation Register, SAR）**架构。其核心原理是在时钟驱动下，通过电容网络（CDAC）进行电荷再分配，以二分法（Binary Search）逐位逼近输入电压。在此过程中，**采样保持时间**和**输入源阻抗**是决定转换精度的物理瓶颈。我们将推导阻抗匹配公式，分析高频采样下的信号失真成因。

### 2. 通道配置序列化与扫描机制（Channel Sequencing）
在多通道采样的实际应用中，单通道采集无法满足多维度物理量监测的需求。STM32 的 ADC 提供了强大的**规则通道组（Regular Group）**与**注入通道组（Injected Group）**。通过配置转换序列（Ranks），ADC 可以在单次触发下，按顺序自动切换模拟通道并进行转换。我们将剖析扫描模式（Scan Mode）、连续转换模式（Continuous Mode）与间断模式（Discontinuous Mode）的工作细节及应用场景。

### 3. 定时器硬件触发机制（Hardware Triggering）
如果使用软件触发（Software Trigger）或延时函数来控制采样间隔，CPU 响应延迟与指令执行抖动会引入不可忽视的**采样抖动（Jitter）**，从而在频域产生相位噪声，降低系统信噪比（SNR）。本章将详细介绍如何通过定时器的 **TRGO（Trigger Out）** 信号线直接硬件触发 ADC 启动转换，实现纳秒级精确对齐的等间隔采样。

### 4. 硬件过采样与均值滤波方法
对于受随机高频噪声（如热噪声、开关噪声）污染的信号，可以通过**硬件过采样（Hardware Oversampling）**技术在硬件内部直接累加多次采样值并进行移位处理，以牺牲采样率换取等效位数（ENOB）的提升。此外，结合软件层面的**增量式滑动平均滤波**与**定点数一阶滞后滤波**算法，可进一步清除带内低频纹波，降低主控 CPU 的计算开销。
