# 前言

在现代嵌入式系统、工业控制、电机伺服驱动、数字电源以及医疗仪器等高精度、实时性要求极高的应用场景中，模拟信号的数字化采集（Analog-to-Digital Conversion, ADC）是一项至关重要的基础功能。如何实现**高吞吐量、多通道、低延迟且零 CPU 干预**的 ADC 数据流搬运，是衡量系统级芯片（SoC）底层架构设计与嵌入式固件工程师水平的重要指标。

在传统的单片机开发中，开发者常使用以下两种方式获取 ADC 数据，但在高性能、高频采样场景下，它们会暴露出致命缺陷：
*   **CPU 轮询（Polling）方式**：CPU 发出启动信号后必须死等（Busy-waiting）转换结束标志位（EOC）。这种同步阻塞模式极大地浪费了主频资源，在高采样率下会导致主循环（Main Loop）卡死，无法处理其他实时任务。
*   **中断触发（Interrupt-driven）方式**：单次转换完成或一轮扫描结束后触发 EOC 中断，由 CPU 在中断服务函数（ISR）中读取结果。虽然避免了死等，但当采样率提升至数百 kHz 乃至 MHz 级时，高频中断会使 CPU 频繁执行现场保护和恢复（Context Switch Overhead），甚至引发“中断风暴（Interrupt Storm）”。CPU 时间几乎被中断处理程序蚕食殆尽，导致关键业务线程（如电机矢量控制算法、通信协议栈）因发生中断饥饿而崩溃。

为了彻底解决这一性能瓶颈，STM32 系列微控制器集成了强大的**直接内存访问控制器（Direct Memory Access, DMA）**。DMA 可以直接接管总线控制权，充当外设与内存之间的“高速公路专职司机”。在不需要 CPU 介入的情况下，硬件自动将 ADC 转换完成的数据搬运至指定的 SRAM 缓冲区中，转换完成时仅通过一次 DMA 传输完成中断（TC）或者半传输中断（HT）来通知 CPU 进行数据处理。

## 本书内容大纲与核心目标

本书旨在从底层寄存器时序、AHB/APB 总线架构、DMA 仲裁优先级、Cache 一致性以及内存对齐等微观视角，深入剖析 STM32 中“DMA + ADC 多通道”的高速采集机制。全书共分为两大部分：

### **第一部分：ADC 多通道高速采样**
*   **[多通道采样与滤波导读](sampling/README.md)**：介绍模拟采集的核心物理瓶颈与本章的理论基础。
*   **[第一章：ADC 多通道扫描与硬件触发机制](sampling/multichannel-scan.md)**：
    *   剖析 ADC 逐次逼近型（SAR）架构的电容 CDAC 电荷分配物理过程。
    *   推导采样时间（Sampling Time）与输入源阻抗的指数衰减数学约束公式。
    *   介绍规则组扫描模式（Scan Mode）与通道序列排布规律。
    *   探讨如何利用定时器 TRGO 信号硬件触发 ADC 采样，彻底消除软件延迟带来的采样抖动（Jitter）。
*   **[第二章：硬件过采样与均值滤波算法](sampling/hardware-oversampling-filtering.md)**：
    *   推导硬件过采样的增益提升与等效有效位数（ENOB）计算公式。
    *   提供增量式滑动平均滤波（$O(1)$ 时间复杂度）与定点数一阶滞后滤波的 C 语言实现。
    *   介绍一维卡尔曼滤波器原理与微控制器轻量级实现。
    *   讨论 PCB 级别的抗干扰设计（AGND/DGND 隔离、RC 抗混叠滤波器、精密参考源等）。

### **第二部分：DMA 高速数据搬运**
*   **[DMA 数据搬运导读](dma/README.md)**：介绍高速数据流的底层总线传输原理与架构。
*   **[第三章：DMA 传输原理与双缓冲区双端口机制](dma/adc-dma-principles.md)**：
    *   详解 APB 外设总线与 AHB 内存总线之间的 DMA 握手信号（`dma_req`/`dma_ack`）和传输状态机。
    *   结合多层 AHB 总线矩阵，深入探讨 DMA 与 CPU 并发访问时的总线冲突（Bus Contention）以及 Overrun 溢出错误的成因与恢复机制。
    *   解析双缓冲区（乒乓缓冲）的底层硬件时序（HT/TC 触发流程）。
    *   针对 Cortex-M7/M4 提供生产级 HAL/LL 驱动架构，分析 D-Cache 一致性维护的最佳实践。

## 预备知识与硬件说明

本书的代码范例和硬件解析主要基于以下平台和规范：
1.  **架构基础**：ARM Cortex-M4/M7（如 STM32F4, STM32F7, STM32G4, STM32H7）。这些芯片拥有先进的 AHB 总线矩阵（Bus Matrix），支持多主控并发访问不同的内存块（SRAM1, SRAM2, DTCM 等）。
2.  **软件规范**：采用生产环境常用的 **C99/C11 语言标准**。核心驱动提供基于寄存器级/LL（Low-Layer）库与HAL（Hardware Abstraction Layer）相结合的优化代码，注重无锁（Lock-free）设计与内存屏障（DMB/DSB）的应用。
3.  **时钟与精度**：针对高精度测量，重点讨论如何利用定时器触发（Timer Trigger）而非软件触发，消除 ADC 采样抖动（Jitter）。
