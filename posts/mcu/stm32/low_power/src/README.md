# 前言与学习目标

在当今的物联网（IoT）、可穿戴设备和分布式传感器网络中，**低功耗设计（Low Power Design）** 已成为衡量系统工程质量的核心指标之一。对于许多依靠纽扣电池（如 CR2032）或微型锂电池供电的嵌入式系统，其设计目标往往是要求单次充电或单节电池能够连续运行数年。这意味着系统的静态电流（底电流，Standby/Stop Current）必须控制在**微安级（$\mu\text{A}$）甚至纳安级（$\text{nA}$）**。

STM32 系列微控制器（尤其是 STM32L0/L4/L5/U5 等超低功耗系列）提供了极为丰富的低功耗模式、灵活的时钟树配置以及细粒度的外设电源管理。然而，在实际工程中，许多开发者常遇到以下痛点：
1. **“调用了休眠 API，但电流依然有几毫安（$\text{mA}$）”** —— 忽视了 GPIO 悬空、引脚上下拉冲突或外设倒灌电流。
2. **“系统进入 Stop 模式后无法唤醒，或者唤醒后直接卡死”** —— 时钟树未正确恢复、中断向量未重映射或唤醒事件配置错误。
3. **“低功耗模式下看门狗复位”** —— 未处理好独立看门狗（IWDG）在休眠期间的喂狗或暂停机制。

本手册旨在从**底层硬件原理与寄存器配置**出发，结合**量产级 C 语言驱动代码**，系统性地梳理 STM32 低功耗设计中的关键路径，帮助系统工程师实现极致的功耗优化。

## 本书内容大纲

本书共分为三个核心章节，环环相扣，从理论分析走向实战调优：

### [1. STM32 低功耗模式深度剖析](./01_low_power_modes.md)
* 深入探讨 STM32 的电源域划分（$V_{\text{DD}}$、$V_{\text{DDA}}$、$V_{\text{CORE}}$、$V_{\text{BACKUP}}$）。
* 详解内部电压调节器（LDO 与 SMPS）的工作原理及动态电压调整（VOS）。
* 细致对比 Sleep、Stop 0/1/2、Standby、Shutdown 等低功耗状态下的电流消耗、唤醒时间及 RAM 保持能力。

### [2. GPIO 漏电流控制与引脚上下拉设计](./02_leakage_current_gpio.md)
* 分析 GPIO 漏电流的物理机制：输入施密特触发器振荡、引脚电平冲突。
* 剖析**外设寄生带电（倒灌电流）**现象及其对 ESD 保护二极管的影响。
* 给出低功耗状态下 GPIO 引脚的配置黄金法则，重点说明**模拟输入（Analog Mode）**的应用。

### [3. 低功耗唤醒源配置与休眠唤醒实战](./03_low_power_wakeups.md)
* 比较 `WFI` 与 `WFE` 指令的执行差异与内核状态机的响应过程。
* 实战配置 EXTI 外部中断、RTC 定时唤醒、LPTIM 低功耗定时器，并分析低功耗下的看门狗（IWDG）管理。
* 提供一套**生产级别的低功耗管理框架代码**，包含休眠前 GPIO 状态备份与隔离、低功耗进入、唤醒后时钟与 GPIO 恢复的全套逻辑。

## 核心学习目标

通过阅读并实践本手册的内容，您将掌握：
* [x] **电源域级配置**：能够根据应用场景选择最适合的低功耗模式，并在运行模式下合理使用动态电压等级（Voltage Scaling）和时钟门控（Clock Gating）来降低功耗。
* [x] **漏电流排查与根治**：能够通过电路原理图分析并计算出 GPIO 漏电流，掌握使用模拟输入状态隔离未使用引脚的技术，彻底解决外设倒灌电流（寄生供电）问题。
* [x] **量产级低功耗框架设计**：掌握在进入休眠前对所有 GPIO 进行状态保存与失能、唤醒后毫秒级重建主时钟（PLL）和外设初始化的标准流程。
* [x] **低功耗调试技能**：掌握在低功耗状态下保持 SWD/JTAG 调试连接的方法，以及通过 DBGMCU 寄存器辅助排查电流异常的实用技巧。
