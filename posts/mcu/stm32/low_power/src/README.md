# STM32 低功耗设计与底电流优化指南

在当今物联网（IoT）、可穿戴设备、智能抄表（Water/Gas/Electricity Meters）以及分布式无线传感器网络中，**低功耗设计（Low Power Design）** 已成为衡量硬件与底层固件工程质量的核心指标。许多依靠锂亚电池或纽扣电池（如 CR2032，容量仅为约 $220\text{mAh}$）供电的嵌入式系统，其设计生命周期往往长达 5 到 10 年。这意味着整机系统的静态电流（即底电流，Standby/Stop Current）必须被严格压低至**微安级（$\mu\text{A}$）甚至纳安级（$\text{nA}$）**。

STM32 系列微控制器（特别是 STM32L0/L4/L5/U5 以及 STM32H7U/W 系列超低功耗微控制器）提供了极具弹性的低功耗工作模式、细粒度的外设时钟树门控（Clock Gating）以及独立电源域控制。然而，在实际工程研发中，许多开发者常面临以下技术痛点：
1. **“调用了休眠 API，但整机电流依然有几毫安（$\text{mA}$）”** —— 忽视了 GPIO 悬空产生的 CMOS 输入横流、引脚上下拉阻抗冲突、或未关闭外设的漏电倒灌（寄生带电）。
2. **“系统进入 Stop 模式后无法被正常唤醒，或者唤醒后瞬间卡死/复位”** —— 时钟源（MSI/HSI）唤醒后未正确重建主时钟（PLL）、中断向量表未正确重映射或唤醒事件标志未清除。
3. **“低功耗模式下意外触发独立看门狗（IWDG）复位”** —— 忽视了休眠期间 IWDG 的冻结位（IWDG_STOP）配置，或者未设计合理的周期性唤醒喂狗机制。

本手册针对这些底层机制、硬件特性和固件开发难点，从**半导体物理、微控制器寄存器级别配置**出发，结合**量产级 C 语言驱动代码**，系统性地拆解 STM32 的低功耗优化全路径。

## 本书内容大纲

本书共分为两个核心部分，包含三个技术专题与两个导引，环环相扣，从硬件原理走向实战调优：

### [第一部分：低功耗模式架构](modes/README.md)
* **[低功耗模式导引](modes/README.md)**：介绍 MCU 低功耗状态机、外设时钟域、电压缩放（Voltage Scaling）与唤醒源的全局图景。
* **[第一章：Sleep、Stop、Standby 与 Shutdown 模式比较](modes/low-power-modes.md)**：深度剖析 STM32 电源域（$V_{\text{DD}}$、$V_{\text{DDA}}$、$V_{\text{CORE}}$、$V_{\text{BACKUP}}$）、主电压调节器（MR）与低功耗稳压器（LPR/SMPS）转换原理，详解动态电压调整（VOS）对 CMOS 动态功耗的平方级节电效应，对比各种低功耗状态下的 RAM 保持力与唤醒时间延迟。
* **[第二章：内部 RTC 与外部中断低功耗唤醒源机制](modes/low-power-wakeups.md)**：深入探讨 `WFI` 与 `WFE` 指令的微架构执行差异，分析 EXTI 外部中断防抖设计的防多次唤醒硬件原理，详解 LPTIM 与 RTC 闹钟（Alarm）以及周期唤醒（WUT）时钟源配置，提供量产级看门狗（IWDG）低功耗共存方案。

### [第二部分：底电流治理与外设裁剪](optimization/README.md)
* **[底电流治理导引](optimization/README.md)**：系统介绍未分配引脚的阻抗状态配置、硬件低通滤波器（RC Filter）对唤醒引脚的保护、以及微安级/纳安级电流测量仪器的电路接线原则。
* **[第三章：漏电流成因分析与未分配 GPIO 状态优化](optimization/leakage-current-gpio.md)**：分析 GPIO 内部施密特触发器在悬空引脚下的偏置跨导横流（Shoot-through Current）物理机制，剖析外设切断供电后通过 ESD 保护二极管产生倒灌电流（Back-Powering）的寄生供电路径，并提供基于 STM32 LL 库编写的休眠前引脚隔离与唤醒后状态恢复的完整硬件抽象层固件。

## 核心学习目标

通过阅读并实践本手册的内容，您将掌握以下工程技能：
* [x] **芯片级电源管理能力**：能根据产品用电模型（例如：极低占空比的温湿度传感器、常在线的穿戴设备）选择最适合的低功耗模式，并在运行模式下利用 Voltage Scaling 和时钟分频优化动态电流。
* [x] **漏电流排查与硬件隔离**：能通过原理图分析并计算出 GPIO 的漏电流通路，掌握应用模拟输入状态（Analog Input）彻底隔离未使用引脚，解决通信总线（UART/SPI/I2C）导致的倒灌漏电问题。
* [x] **生产级低功耗控制固件**：掌握在进入休眠前对所有 GPIO 进行状态保存与隔离、唤醒后毫秒级重建主时钟（PLL/HSE）以及重建外设硬件状态的标准流程。
* [x] **低功耗开发调试与测量**：掌握如何在低功耗模式下保持 SWD 调试连接，以及使用 DBGMCU 寄存器辅助排查，并理解分流电阻（Shunt Resistor）与反馈放大器（Feedback Ammeter）在超低电流测量中的差异与防陷阱技巧。
