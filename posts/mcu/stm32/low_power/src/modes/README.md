# 第一部分：低功耗模式架构

本部分主要阐述 STM32 微控制器的底层电源管理、时钟分配和内核休眠唤醒状态机。深入理解这部分内容，是设计出能够进入微安级甚至纳安级底电流，同时又能实现快速、可靠唤醒的嵌入式系统的基石。

---

## 1. MCU 低功耗状态与模式层级

STM32 提供了一系列由浅入深的低功耗状态，以便开发者在**功耗（Power Consumption）**、**唤醒时间（Wakeup Latency）**和**上下文保持能力（Context Retention）**之间找到最佳平衡点点：

1. **Sleep 模式**：仅关闭 CPU 内核时钟，所有外设和 SRAM 依然带电并正常运行。功耗处于毫安级，唤醒时间最短（几个系统时钟周期）。
2. **Stop 0/1/2 模式**：完全关断 $V_{\text{CORE}}$ 域中的所有高速时钟（PLL, HSE, HSI），但 SRAM 和寄存器状态保持。在 Stop 2 模式下，静态电流可降至 $1\,\mu\text{A}$ 左右。
3. **Standby 模式**：$V_{\text{CORE}}$ 域完全断电，SRAM（除部分型号的 SRAM2）和外设寄存器丢失，唤醒相当于热复位。底电流降低至数百纳安。
4. **Shutdown 模式**：MCU 最极限的低功耗模式，内部 LDO/SMPS 完全关闭，LVD 等监控电路也停止工作，仅保留最基本的唤醒引脚和外部 RTC 时钟源。底电流仅几十纳安。

```
              ┌────────────────────────┐
              │     RUN (Full Speed)   │
              └───────────┬────────────┘
                          │ (WFI/WFE, SLEEPDEEP=0)
                          ▼
              ┌────────────────────────┐
              │         SLEEP          │
              └───────────┬────────────┘
                          │ (WFI/WFE, SLEEPDEEP=1, LPMS=Stop)
                          ▼
              ┌────────────────────────┐
              │     STOP (0 / 1 / 2)   │
              └───────────┬────────────┘
                          │ (WFI/WFE, SLEEPDEEP=1, LPMS=Standby)
                          ▼
              ┌────────────────────────┐
              │        STANDBY         │
              └───────────┬────────────┘
                          │ (WFI/WFE, SLEEPDEEP=1, LPMS=Shutdown)
                          ▼
              ┌────────────────────────┐
              │        SHUTDOWN        │
              └────────────────────────┘
```

## 2. 外设时钟域与时钟树门控 (Clock Gating)

在 CMOS 集成电路中，动态功耗直接正比于工作频率：
$$P_{\text{dynamic}} = C \cdot V^2 \cdot f$$
当时钟处于翻转状态时，寄生电容不断充放电会消耗大量电能。因此，STM32 划分了极其细致的时钟树：
* **高速时钟源**：HSE (外部高速)、HSI (内部高速)、MSI (内部多速)、PLL (锁相环)。在进入 Stop 模式后，这些振荡器将全部停振。
* **低速时钟源**：LSE (外部低速，主要供 RTC 使用)、LSI (内部低速，主要供看门狗使用)。在休眠期间，仅保留这些低速时钟以支持定时唤醒。
* **时钟门控（Clock Gating）**：在运行模式下，通过 RCC（Reset and Clock Control）寄存器（如 `RCC_AHBxENR` / `RCC_APBxENR`）关闭未使用的外设时钟，切断该外设内部触发器的翻转，可减少多达 70% 的芯片运行功耗。

---

## 3. 电压缩放与调节器控制 (Voltage Scaling)

为了满足不同主频下的时序裕量（Timing Margin），同时降低低速运行时的功耗，STM32 $V_{\text{CORE}}$ 域支持**动态电压调整（VOS, Voltage Scaling）**：
* **Range 1 (高性能模式)**：$V_{\text{CORE}}$ 供给高电压（如 $1.2\text{V}$），支持 CPU 满频工作。
* **Range 2 (低功耗模式)**：$V_{\text{CORE}}$ 供给低电压（如 $1.0\text{V}$），虽然限制了 CPU 主频，但因为功耗与电压的平方成正比，可实现极佳的动态能效比。

除了 LDO（线性降压稳压器）外，超低功耗系列还集成了高效率的 **SMPS（开关稳压器）**，通过电感储能换能，在运行模式下能将功耗进一步降低 50% 以上。

---

## 4. 低功耗唤醒源分类

要从低功耗状态安全退回到 Run 模式，必须配置好唤醒源。主要包括以下几类：
1. **外部中断唤醒 (EXTI)**：由 GPIO 状态变化（上升沿/下降沿）触发，可在 Stop 模式下工作。
2. **定时唤醒源 (RTC/LPTIM)**：基于低速时钟（LSE/LSI）运行，支持数十秒至数天的周期性定时唤醒，是物联网设备常态休眠的核心组件。
3. **硬件唤醒引脚 (WKUP)**：专门用于从 Standby 和 Shutdown 这种深层断电模式中直接拉起 MCU。
4. **外设接口特殊事件**：例如 I2C 地址匹配唤醒、LPUART 接收到特定帧唤醒等，使得 MCU 能在保持休眠的状态下对总线数据做出响应。
