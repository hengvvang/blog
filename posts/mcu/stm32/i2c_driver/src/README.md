# STM32 软件模拟 I2C 驱动与总线时序实现

I2C（Inter-Integrated Circuit）是一种同步、半双工、多主从结构的串行通信总线。在嵌入式开发中，虽然 STM32 系列微控制器通常内置了硬件 I2C 控制器，但在许多实际工程项目中，开发者往往更倾向于使用 GPIO 软件模拟（Bit-Banging）I2C。这主要源于 STM32 早期型号（如经典的 STM32F103 系列）硬件 I2C 控制器存在著名的硅片级设计缺陷（Silicon Bugs），在复杂噪声或中断嵌套环境下极易产生总线 busy 标志锁死、SCL/SDA 被意外拉低等死锁现象。此外，软件模拟 I2C 具有引脚选择极其灵活、移植性强、协议时序完全可见且易于断点调试等显著优势。

本手册旨在系统、深入地讲解如何在 STM32 平台上实现生产级的软件模拟 I2C 驱动，并深入分析总线死锁的成因与规避策略。

---

## 本书内容概览

本手册共分为三个章节，由浅入深，从底层的物理电平逻辑逐步过渡到健壮的驱动框架设计：

### 1. [GPIO 软件模拟时序与物理电平](01_i2c_timing_simulation.md)
* **物理层电平特征**：深入剖析开漏输出（Open-Drain）与线与（Wired-AND）逻辑，探讨上拉电阻对信号上升沿的影响，以及从机时钟拉伸（Clock Stretching）的机制。
* **GPIO 寄存器控制**：详细讲解如何使用 STM32 寄存器（MODER、OTYPER、BSRR、IDR）实现免方向切换的开漏模式高速读写优化。
* **时序精确模拟**：使用 Cortex-M 内核的 DWT（数据观察点和跟踪）外设实现微秒级精确延时，逐行代码剖析 START、STOP、ACK、NACK 及字节读写操作。

### 2. [STM32 硬件 Bug 与从机死锁成因](02_hardware_bugs_deadlocks.md)
* **STM32 硬件 I2C 硅缺陷剖析**：分析硬件 I2C 状态机在极高或极低速、中断嵌套时产生 `BUSY` 标志卡死的物理机制。
* **从机死锁（拉低 SDA）现象**：重点探讨在通信中途 Master 被异常复位（如 Watchdog 复位、调试挂起）后，Slave 持续拉低 SDA 导致总线瘫痪的场景。
* **总线恢复逻辑（Bus Recovery）**：详述通过发送“9个脉冲（Clocks of Death）”强制释放 SDA 的原理，并提供完整的 C 语言总线恢复代码。

### 3. [健壮驱动设计与防死锁策略](03_robust_driver_design.md)
* **多实例面向对象封装**：通过 C 语言结构体 `I2C_HandleTypeDef` 封装引脚、端口和延时参数，支持多路 I2C 实例动态并发。
* **全流程超时退出（Timeout）**：引入非阻塞计时机制，防止因从机无响应、时钟拉伸超时而导致主线程无限挂起。
* **线程安全与临界区保护**：探讨在 FreeRTOS 等实时操作系统中，如何利用 Mutex 保护总线，避免多任务并发导致的时序交织。
* **应用示例**：提供基于该驱动读写标准 EEPROM（如 AT24C02）的完整参考实现。

## 学习目标

通过阅读本手册，您将能够：
1. **理解本质**：掌握 I2C 总线开漏输出和物理上拉带来的电平特性，深刻理解信号上升/下降沿的物理限制。
2. **编写生产级驱动**：摒弃粗暴的 `for(volatile int i=0);` 延时，使用 DWT 周期计数器实现高精度、确定性的时序控制，并学习免引脚方向切换的高效配置方法。
3. **解决死锁难题**：能够自信地面对并解决工业现场因静电、电源抖动或 MCU 意外复位引发的“SDA 拉低”死锁故障，为系统编写自动总线恢复逻辑。
4. **设计优美架构**：将驱动分为物理 GPIO 模拟层与设备协议层，设计出可移植性高、抗干扰能力强的多实例 I2C 驱动框架。
