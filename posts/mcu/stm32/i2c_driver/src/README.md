# STM32 软件模拟 I2C 驱动与总线时序实现

I2C（Inter-Integrated Circuit）是由 Philips 公司（现为 NXP）开发的一种同步、半双工、多主从结构的串行通信总线。在嵌入式系统开发中，虽然 STM32 系列微控制器通常内置了硬件 I2C 控制器，但在许多实际工程项目中，开发者往往更倾向于使用 **GPIO 软件模拟（Bit-Banging）I2C**。

这主要源于以下几个深层次的技术考量：
1. **避开硅片设计缺陷**：STM32 早期型号（如经典的 STM32F103 系列）硬件 I2C 控制器存在著名的硅片级设计缺陷（Silicon Bugs），在复杂噪声、高负载或多中断嵌套的实时系统环境下极易产生总线忙状态锁死、SCL/SDA 被意外拉低等灾难性故障。
2. **硬件引脚极其灵活**：硬件 I2C 引脚是固定的，如果 PCB 布线受限，只能通过软件模拟 I2C 利用任意通用 GPIO 组合进行通信。
3. **极强的高移植性**：软件模拟 I2C 代码只依赖于底层的 GPIO 控制和微秒级延时，可以实现跨平台（从 Cortex-M0 到 M7，甚至 51 单片机、DSP 和 Linux）的无缝移植。
4. **时序完全可见与可调**：物理时序完全由软件代码控制，易于通过逻辑分析仪和示波器进行断点调试与微调。

本手册旨在系统、深入地讲解如何在 STM32 平台上实现生产级的软件模拟 I2C 驱动，并深度剖析总线死锁的成因与规避策略。

## 本书内容架构

本手册共分为三个部分，由浅入深，从物理层的电平逻辑逐步过渡到高可靠性的驱动框架设计：

### 第一部分：软件模拟时序

本部分重点解析 I2C 物理层基础特性，并演示如何利用 GPIO 引脚和高精度计数器精确模拟物理时序：
* **[软件模拟时序与 GPIO](simulation/README.md)**：介绍 I2C 总线物理电平特征、起始与停止条件的基本定义。
* **[第一章：GPIO 软件模拟时序与物理电平](simulation/i2c-timing-simulation.md)**：
  * **开漏输出与线与逻辑**：深入剖析开漏驱动器结构、外部上拉电阻与寄生电容对信号上升时间（\\(t_r\\)）的物理影响。
  * **从机时钟拉伸（Clock Stretching）**：探讨从机通过拉低 SCL 进行流控的物理机制及主机侧的接收逻辑。
  * **GPIO 优化控制**：详细讲解如何使用 STM32 的 BSRR/IDR 寄存器，实现免方向切换的开漏双向读写。
  * **高精度延时**：使用 Cortex-M 内核的 DWT 计数器（CYCCNT）实现高精度的微秒阻塞延时。

### 第二部分：硬件缺陷与死锁恢复

本部分深入探讨系统崩溃及断电导致的物理死锁现象，并提供底层硬核的解决方案：
* **[硬件缺陷与死锁](deadlocks/README.md)**：简述死锁种类及通过时钟脉冲破坏死锁的机制。
* **[第二章：STM32 硬件 Bug 与从机死锁成因](deadlocks/hardware-bugs-deadlocks.md)**：
  * **STM32 芯片级缺陷**：剖析在中断抢占情况下，硬件 I2C 内部状态寄存器清零机制失效的硅片故障机理。
  * **从机拉低 SDA 锁死**：深度推演主机中途异常复位后，从机因等待时钟沿而永久拉低 SDA、主控因检测总线繁忙而不敢发送 START 导致的物理闭环死锁。
  * **总线自愈恢复（Bus Recovery）**：详解发送 9 个时钟脉冲（死亡脉冲）强制从机完成发送并释放 SDA 的物理逻辑，并给出完整的 C 语言 GPIO 物理级自愈函数。

### 第三部分：健壮驱动架构设计

本部分专注于将底层时序与恢复机制融合，实现面向多实例、在实时操作系统下并发安全的生产级驱动：
* **[健壮驱动设计](drivers/README.md)**：介绍三层驱动架构体系、非阻塞超时以及并发互斥概念。
* **[第三章：健壮驱动设计与防死锁策略](drivers/robust-driver-design.md)**：
  * **面向对象多通道句柄**：定义 `SoftI2C_HandleTypeDef`，实现一套驱动多路并发实例的优雅封装。
  * **非阻塞超时机制（Timeout）**：在所有状态等待循环中嵌入自减计时判定，防止异常情况导致的主线程死锁卡死。
  * **多任务并发安全**：深度融合 FreeRTOS 的互斥锁（Mutex）与优先级继承算法，解决多任务访问时序交织及优先级翻转问题。
  * **设备适配范例**：提供基于此驱动读取标准 EEPROM（AT24C02）的生产级完整源码与多任务测试方案。

## 预期学习目标

完成本手册的学习后，您将能够：
1. **洞悉物理特性**：深刻理解上拉电阻、总线寄生电容以及 RC 充电常数对波形沿的影响，能够运用数学工具定量分析总线物理约束。
2. **编写高效驱动**：告别粗暴的 `for` 循环软件模拟，掌握 DWT 精确微秒级延迟及开漏读写的免方向切换优化。
3. **彻底解决死锁**：在复杂且受干扰的工业控制现场，能够自信地编写总线自愈恢复代码，自动处理并打破 SDA 被从机永久拉低的致命僵局。
4. **设计健壮架构**：掌握多实例面向对象封装和并发保护锁机制，设计出模块化、高复用、抗电磁干扰的工业级外设驱动模块。
