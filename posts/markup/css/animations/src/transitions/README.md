# 第一部分：CSS 过渡与缓动物理

在现代 Web 界面设计中，过渡（Transition）是建立连续状态流、构建自然微交互的核心技术。它能消除突兀的界面状态突变，让用户感知到操作的连续性与空间关系。

本部分将深入研究 CSS 过渡的底层运作机理，重点探讨三次贝塞尔曲线（Cubic Bézier Curves）的数学建模以及如何利用它们模拟物理世界中的弹性阻尼（Spring Physics）。

---

## 1. CSS 过渡（Transitions）核心要素

CSS 过渡由以下四个关键属性协同控制，其复合简写形式为 `transition`：

*   **`transition-property`**：指定哪些 CSS 属性应当参与过渡插值（如 `transform`、`opacity`、`background-color`）。为保障渲染性能，应严格遵循 Composite-Only 路径，尽量仅对 `transform` 与 `opacity` 进行过渡。
*   **`transition-duration`**：过渡的持续时间（如 `300ms` 或 `0.3s`）。过长会导致界面拖沓，过短则会使人眼难以捕捉。
*   **`transition-timing-function`**：过渡的时间轴插值函数，它决定了过渡值在时间维度上的变化率（速度曲线）。支持 `linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out` 以及自定义的 `cubic-bezier()` 与 `steps()`。
*   **`transition-delay`**：过渡的启动延迟时间。常用于多元素入场的级联动画排版。

---

## 2. 三次贝塞尔曲线与数学建模

除了预设的缓动关键字外，CSS 允许通过 `cubic-bezier(x1, y1, x2, y2)` 定义自定义的三次贝塞尔曲线。

数学上，三次贝塞尔曲线由四个控制点决定：
*   $P_0(0, 0)$：固定的起始时间与起始进度点。
*   $P_1(x_1, y_1)$：第一个自定义控制点，决定起始阶段的加速度。
*   $P_2(x_2, y_2)$：第二个自定义控制点，决定结束阶段的减速度。
*   $P_3(1, 1)$：固定的结束时间与结束进度点。

### 贝塞尔曲线时域映射示意图

```text
    y (输出进度 Output Progress / Property Value)
    ^
1.0 |--------------------------------------* P3 (1.0, 1.0)
    |                                   .  |
    |                                 .    |         * P2 (x2, y2)
    |                               .      |        /
    |                             .        |       /
    |                           .          |      /
    |                         .            |     /
    |                       .              |    /
    |               *     .                |   /
    |              /    .                  |  /
    |             /   .                    | /
    |            /  .                      |/
    |           * P1 (x1, y1)
    |         .
0.0 +---------------------------------------> x (时间进度 Time Progress)
   0.0                                    1.0
```

当 $x_1, x_2$ 限制在 $[0, 1]$ 之间时（确保时间线性流逝），$y_1, y_2$ 却可以大于 $1$ 或小于 $0$。正是这种数学特性，使得我们能越过原本的起点和终点限制，构建出物理学中的“回弹”与“过冲”效果。

---

## 3. 弹簧阻尼物理仿真（Spring Physics Simulation）

现实物理世界中的物体由于质量和弹性阻尼的存在，在受力移动到目标位置时并不会瞬间静止，而是通常会产生不同程度的**回弹（Overshoot / Bounce）**和**前置下蹲准备（Anticipation）**。

在 CSS 中，虽然我们无法直接书写质点弹性微分方程，但可以通过精细调校 `cubic-bezier` 的控制点来极高精度地拟合阻尼振动方程：

*   **前置下蹲（Anticipation）**：设置 $y_1 < 0$，元素在向目标方向运动前，会先反向微动。
*   **物理过冲（Overshoot）**：设置 $y_2 > 1.0$，元素到达目标位置后会越过终点，然后被拉回终点。

### 阻尼震动曲线与贝塞尔拟合对比

```text
 进度 (y)
   ^
1.2|             _..-* P2(x2, y2 > 1.0) ──> 产生物理过冲 (Overshoot)
   |          .-'
1.0|--------.'-----------------------------* P3(1,1)
   |       /
   |      /
   |     /
   |    /
   |   * P1(x1, y1 < 0) ──> 产生前置下蹲 (Anticipation)
0.0|--'------------------------------------> 时间 (x)
```
