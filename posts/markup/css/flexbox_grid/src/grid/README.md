# Grid 网格与响应式

本部分将深入探讨 CSS Grid Layout (网格布局) 的全局架构与响应式设计。作为 CSS 历史上最强大的二维布局引擎，Grid 允许开发者在水平与垂直两个维度上同时构建复杂的网格结构，实现无缝的卡片对齐、重叠布局以及现代自适应布局。

## 核心技术要点

### 1. 网格结构与轨道划分 (Grid Tracks & Templates)
通过 `grid-template-columns` 和 `grid-template-rows` 属性，开发者可以显式定义网格的行与列轨道。
- 支持使用物理单位（如 `px`）、相对单位（如 `%`、`em`）。
- 支持现代网格专属单位 `fr`（分数单位，表示可用剩余空间的按比例分配份数）。
- 提供便捷函数如 `repeat()`、`minmax()` 以及自适应关键字 `auto-fit` 与 `auto-fill`。

### 2. 网格区域与命名命名坐标 (Grid Areas & Coordinates)
除了通过网格线索引（如 `grid-column: 1 / 3`）定位元素外，CSS Grid 引入了直观的**网格模板区域 (Template Areas)**：
- 利用 `grid-template-areas` 可以用可视化的 ASCII 字符画声明网格结构。
- 子项通过 `grid-area: <name>` 直接绑定到对应的网格区域。

```
        +-------------------------------------------+
        |                 header                    |
        +------------------+------------------------+
        |                  |                        |
        |     sidebar      |          main          |
        |                  |                        |
        +------------------+------------------------+
        |                 footer                    |
        +-------------------------------------------+
```

### 3. 自动放置算法 (Auto-placement Algorithms)
当子项超出显式网格边界，或者未指明网格线坐标时，隐式网格（Implicit Grid）会自动创建。
- 通过 `grid-auto-flow` 控制自动放置的方向（`row`、`column`）。
- 开启 `dense`（紧密填充算法）后，浏览器会以非 DOM 顺序的填充方式，强行回填之前留下的空隙，非常适合瀑布流及卡片画廊。

### 4. 响应式网格布局最佳实践
传统响应式依赖 `@media` 设备宽度断点。而 CSS Grid 通过 `minmax()` 搭配 `auto-fit` 或 `auto-fill`，可实现无需任何媒体查询的自动折行与自适应延展。
