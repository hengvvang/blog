# 第一部分：Mermaid 基础语法与渲染配置 - 渲染基础

在现代技术文档的编写中，“文档即代码”（Docs as Code）实践要求我们将架构设计、业务流程和数据关系以文本形式维护在版本控制系统中。Mermaid 作为这一领域的佼佼者，通过声明式语法实现了文本到复杂图表的实时渲染。

本部分将深入探讨 Mermaid 的基础架构与渲染底层，包括词法解析、布局计算，以及如何在不同宿主环境中进行深度配置。

---

## 1. 渲染引擎架构概述

Mermaid 的核心是一个“领域特定语言（DSL）编译器”。其工作流程可以划分为两个主要阶段：**解析（Parsing）** 与 **布局/渲染（Layout & Rendering）**。

### 1.1 核心解析流程

```text
+-----------------------+
|  Markdown Code Block  |  <--- 包含 ```mermaid 声明的原始文本
+-----------------------+
            |
            v
+-----------------------+
|    Jison Lexer/Parser |  <--- 词法分析与语法分析，提取 Token 序列
+-----------------------+
            |
            v
+-----------------------+
| Abstract Syntax Tree  |  <--- 构建内存中的抽象语法树（AST）
+-----------------------+
            |
            v
+-----------------------+
|   Config/Theme Merge  |  <--- 合并全局默认配置与自定义 themeVariables
+-----------------------+
            |
            v
+-----------------------+
|     Layout Engine     |  <--- 核心布局计算（如 Dagre 拓扑分层算法）
+-----------------------+
            |
            v
+-----------------------+
|  D3.js SVG Generator  |  <--- 生成符合 W3C 标准的 SVG DOM 元素并绑定事件
+-----------------------+
```

### 1.2 渲染引擎分类
- **Dagre 引擎**：Mermaid 默认的流程图布局引擎，基于有向无环图（DAG）的 Sugiyama 布局算法。它在处理层级分明的拓扑结构时表现优异，但在节点过多时容易出现连线交错。
- **ELK (Eclipse Layout Kernel) 引擎**：新版引入的高级布局引擎，特别适合节点数量庞大（>100）的复杂架构图，支持更为精准的正交布局控制。

## 2. 语法定界符与基础声明

Mermaid 图表通常包裹在标准 Markdown 的代码块中，并指定语言标识符为 `mermaid`：

```text
```mermaid
graph TD
    A --> B
```
```

- **定界符**：开头和结尾的双重三反引号（`` ` ``）是标准的 Markdown 语法。
- **图表类型声明**：代码块第一行指定图表类别（如 `graph`, `flowchart`, `sequenceDiagram`, `stateDiagram-v2` 等）。
- **方向矢量**：紧跟类别声明的是图表的全局绘制方向矢量。

---

## 3. 图表方向矢量 (Graph Direction Vectors)

方向矢量决定了布局引擎在计算坐标时的主轴朝向。常用矢量定义如下：

| 标识符 | 英文全称 | 渲染方向 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **`TB`** / **`TD`** | Top to Bottom / Top Down | 从上至下 | 瀑布式执行流、多级层级结构 |
| **`BT`** | Bottom to Top | 从下至上 | 继承树反向溯源、底座支撑架构 |
| **`LR`** | Left to Right | 从左至右 | 管道流、时序演进、数据清洗线 |
| **`RL`** | Right to Left | 从右至左 | 特定 RTL 语系支持或逆向数据流 |

---

## 4. 节点形状与样式控制 (Nodes Styles)

在流程图中，节点的几何外观决定了其语义。Mermaid 支持丰富的节点边框表达形式：

```text
   +-------------+       +-------------+       /-------------\
   |  [矩形节点]  |       |  (圆角矩形)  |       |  ([体育场])  |
   +-------------+       +-------------+       \-------------/
     标准步骤              分支/状态              开始/结束

     /---------\             /\                   +---------+
    /  /平行/  /            /  \                  | [(数据库)]|
   /----------/            / 决策 \               +---------+
     输入/输出             \  /                   持久化存储
                             \/
```

### 4.1 样式自定义
通过 `classDef` 和 `style` 关键字，我们可以对节点进行精细化视觉管理：
- **`style`**：针对特定节点实例直接配置 CSS 样式属性（如填充色、边框粗细、字体颜色）。
- **`classDef`**：定义一个可复用的 CSS 类，通过 `:::` 语法绑定到一个或多个节点上。
