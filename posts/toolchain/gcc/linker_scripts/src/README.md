# 前言

在现代软件开发中，高级语言的编译与运行往往被高度抽象。特别是在有操作系统（如 Linux 或 Windows）支持的环境下，虚拟内存（Virtual Memory）机制让开发者无需关心程序在物理内存中的具体存放位置。然而，在嵌入式裸机（Bare-metal）开发与实时操作系统（RTOS）的世界里，这种抽象被彻底打破。

嵌入式微控制器（MCU，如 ARM Cortex-M、RISC-V 等）的物理资源极其受限，且拥有多种性质不同的存储介质（如内置 Flash、SRAM、CCRAM、外部 QSPI Flash、SDRAM 等）。对于系统工程师而言，掌控程序中每一段代码、每一个变量的物理存放位置是至关重要的。例如：
*   **中断向量表（Interrupt Vector Table）** 必须精准存放在微控制器上电复位后读取的特定地址（例如 Cortex-M 的 `0x08000000` 或 `0x00000000`）。
*   **关键算法与中断服务程序（ISR）** 需要被搬移到运行速度更快的 SRAM 或紧耦合内存（TCM）中执行，以规避 Flash 读取等待周期，提升实时响应速度。
*   **非易失性数据/配置** 需要放置在特定的 Flash 扇区以进行在线更新，而不能被常规的程序覆盖。
*   **未初始化的大型缓存（Buffers）** 必须合理定位在外部扩展 SDRAM 中，避免撑爆宝贵的内部 SRAM。

实现上述内存规划的核心工具就是**链接器脚本（Linker Script）**。它是指导 GNU 链接器（`ld`）如何合并、重定位以及排布各个输入目标文件（`.o`）的蓝图。

## 本书内容与大纲

本书致力于以生产级的技术深度，全面剖析 GNU 链接器（GNU `ld`）的核心工作机理、链接脚本的语法规则，以及如何通过链接脚本与 C 运行时（C Runtime Startup）配合，实现高度自定义的内存空间分配。

全书分为三个核心章节：

*   **[第一章：链接原理与语法基础](01_linker_phases_syntax.md)**
    深入探讨 GNU 工具链中链接阶段的本质工作流程、重定位与符号解析原理；逐行剖析链接器脚本的基本框架结构，包括 `MEMORY` 命令的属性定义、地址计数器（Location Counter `.`）的累加与对齐规则，以及基本命令的使用。

*   **[第二章：物理存储映射与自定义 Section 分配](02_sections_allocation.md)**
    深度解构标准 Section（`.text`、`.rodata`、`.data`、`.bss`）在物理内存中的映射关系；详解加载地址（LMA）与运行地址（VMA）的本质区别及其应用场景；提供多核/多介质环境下的自定义 Section 分配范例（如将特定代码载入 RAM 运行，将大数组分配至外置存储等）。

*   **[第三章：链接器变量、符号与 C 运行时交互](03_linker_variables_embedded.md)**
    揭示链接器符号（Linker Symbols）在 C 语言中的正确引用与操作方式，对比“链接器变量”与“C 语言普通变量”的底层差异；提供完整的、工业级的 C 语言启动代码（Startup Code）与链接器脚本配合实例，展示如何在上电时执行 `.data` 段搬移和 `.bss` 段清零，并详细分析因对齐、指针操作不当引起的硬件异常（如 HardFault）。

## 学习目标

完成本书的学习后，您将能够：
1. **看懂并独立编写** 适用于任何微控制器平台的 GNU 链接脚本。
2. **精确控制** 任何代码函数或全局变量在硬件内存中的存放地址。
3. **理解并修复** 链接阶段由于内存溢出（Region Overflow）、段冲突、对齐失败引起的各种链接错误。
4. **自主编写** 微控制器的 C 语言启动文件，手动控制 LMA 到 VMA 的数据拷贝与 RAM 运行时环境初始化。
5. **熟练分析** GCC 生成的 `.map` 文件，对其进行静态内存占用的精确审计与优化。
