# 深入浅出嵌入式链接脚本与内存分配

在现代桌面或服务器端软件开发中，底层的物理内存布局往往被操作系统（如 Linux 或 Windows）的虚拟内存管理（VMM）机制所遮蔽，软件工程师一般无需关注特定的代码或变量存放在哪个物理地址上。但在嵌入式裸机（Bare-metal）开发与实时操作系统（RTOS）的世界里，这种高层的抽象将被彻底打破。

作为一个嵌入式系统级工程师，掌控微控制器上每一字节资源的分配、每段代码以及变量的存放位置是至关重要的。例如：
* **中断向量表** 必须放置在控制器复位后首选读取的特定地址。
* **时间敏感的关键函数** 需要在上电时从慢速 Flash 拷贝至快速 SRAM 或紧耦合内存（TCM）中执行，以获得零等待周期的运行效率。
* **外设控制与共享缓存** 必须精确映射至特定物理内存段中，从而配合 DMA 或硬件控制器工作。
* **大容量动态缓冲区** 需要重定向至外部 SDRAM，避免挤占宝贵的内部主 SRAM。

实现上述所有内存规划的最终工具就是**链接器脚本（Linker Script）**。它是指导编译工具链最终链接阶段如何合并重定位目标段的“蓝图”。

## 本书内容与大纲

本书致力于以生产级的技术深度，全面剖析 GNU 链接器（GNU `ld`）的核心工作机理、链接脚本的语法规则，以及如何通过链接脚本与 C 运行时（C Runtime Startup）配合，实现高度自定义的内存空间分配。

全书分为两个核心部分：

### 第一部分：编译链接流程与段分配
* **[编译链接原理](anatomy/README.md)**
  * **[第一章：编译链接阶段与链接脚本基本语法](anatomy/linker-phases-syntax.md)**：深入探讨 GNU 工具链在编译链接阶段的符号解析、重定位和合并工作流，以及链接脚本中 `MEMORY` 命令的属性定义、定位计数器的自增规则。
  * **[第二章：物理/虚拟内存分区与程序段映射机制](anatomy/sections-allocation.md)**：分析 `.text`、`.rodata`、`.data`、`.bss` 等标准段的映射，解析加载地址（LMA）与运行地址（VMA）的差异，并提供一套生产级的链接脚本作为实战分析。

### 第二部分：链接器符号与嵌入式交互
* **[链接器符号](variables/README.md)**
  * **[第三章：C 语言访问链接器符号与栈/堆边界管理](variables/linker-variables-embedded.md)**：探讨如何在 C 代码中通过地址操作符或数组类型安全访问链接脚本定义的物理边界符号，分析内存未对齐对 ARM CPU 造成的致命异常（`HardFault`），以及如何对生成的 `.map` 文件进行静态内存审计。

## 学习目标

完成本书的学习后，您将能够：
1. **看懂并独立编写** 适用于任何微控制器架构（如 ARM Cortex-M/Cortex-A、RISC-V 等）的 GNU 链接脚本。
2. **精确控制** 任何代码函数或全局变量在硬件内存中的存放地址。
3. **理解并修复** 链接阶段由于内存溢出（Region Overflow）、段冲突、对齐失败引起的各种链接错误。
4. **自主编写** 微控制器的 C 语言启动文件，手动控制 LMA 到 VMA 的数据拷贝与 RAM 运行时环境初始化。
5. **熟练分析** GCC 生成的 `.map` 文件，对其进行静态内存占用的精确审计与优化。
