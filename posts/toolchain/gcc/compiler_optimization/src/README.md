# 前言：GCC 编译优化与底层汇编的艺术

在现代软件工程中，编译器不仅是将高级语言翻译为机器码的工具，更是底层性能优化的核心引擎。尤其是对于嵌入式系统、操作系统内核及高频交易等对性能与二进制体积有极端要求的场景，深入理解编译器的优化机制以及掌握与编译器直接对话的**内联汇编（Inline Assembly）**与**链接时优化（LTO）**技术，是每一位资深系统级工程师的必修课。

本手册旨在从**原理、实践、调优与工程落地方案**四个维度，全面剖析 GCC（GNU Compiler Collection）在编译优化及汇编层面的深层机制。

---

## 核心内容大纲

为了帮助读者构建系统化的知识体系，本书将内容划分为以下三个核心章节：

### 1. GCC 优化等级与循环变换 (`01_optimization_levels.md`)
* **多级优化全景对比**：从无优化的 `-O0`，到注重调试的 `-Og`，平衡性能与体积的 `-O2`，激进优化的 `-O3`，兼顾体积的 `-Os`/`-Oz`，再到打破 IEEE 浮点标准的 `-Ofast`。
* **核心编译优化技术详解**：深入探讨死代码消除（DCE）、常量折叠与传播、公共子表达式消除（CSE）、无条件分支消除等。
* **循环优化与变换**：深度剖析循环展开（Loop Unrolling）、循环剥离（Loop Peeling）、自动向量化（SIMD）的底层汇编表象与触发条件。
* **性能与体积的权衡**：如何通过科学的方法评估编译优化对指令缓存（I-Cache）、流水线气泡及二进制文件大小的影响。

### 2. GCC 内联汇编与约束规则 (`02_inline_assembly.md`)
* **内联汇编基础语法**：从 Basic Assembly 到 Extended Assembly 的平滑过渡。
* **四段式语法结构详解**：精细化解读 `__asm__ __volatile__ ( AssemblerTemplate : OutputOperands : InputOperands : Clobbers )`。
* **约束限制（Constraints）的精妙控制**：
  * 通用寄存器约束（`r`）、内存约束（`m`）、立即数约束（`i`、`I`）等。
  * 修饰符的操作：只读、只写（`=`）、可读可写（`+`）以及早期擦除（`&`，Earlyclobber）的竞争机制。
* **Clobber List（破坏列表）与内存屏障**：深入理解 `"memory"` 破坏描述符如何指导编译器重建指令流，防止寄存器重用与指令重排。
* **多架构实战**：提供 Cortex-M (ARMv7-M) 和 x86_64 架构下，针对临界区保护、原子操作、系统调用及高效数据搬运的生产级代码示例。

### 3. 函数内联屏障与链接时优化 (`03_inline_and_link_optimization.md`)
* **函数内联（Inlining）的决策树**：解析编译器如何计算内联代价（Inline Cost），以及 `-finline-functions` 标志的作用。
* **内联屏障与精准控制**：如何通过 `noinline`、`always_inline` 与 `__volatile__` 强制编译器在期望的物理边界停止优化。
* **链接时优化（Link-Time Optimization, LTO）深度解密**：
  * 传统编译流程（编译单元孤立优化）的局限性。
  * LTO 的工作流：从中间表示（GIMPLE 字节码）的生成，到链接阶段的全局 call graph 优化。
  * LTO 在死代码消除（Whole Program WPA/LTRANS）以及跨编译单元内联上的威力。
* **LTO 带来的负面效应与规避**：符号丢失、调试信息（DWARF）降级、构建时间暴增以及静态库依赖的解决方法。

## 学习本手册的收获

完成本书的学习后，您将能够：
1. **看透汇编**：面对复杂的 C/C++ 代码，能够准确预测 GCC 会将其翻译成何种形态的汇编指令。
2. **驾驭性能**：不再盲目使用 `-O3`，而是能根据具体的硬件架构（如 L1 Cache 大小、指令流水线深度）定制最优的编译选项组合。
3. **安全混编**：编写出无副作用、寄存器分配精确、不破坏编译器优化上下文的高性能内联汇编代码。
4. **全局优化**：在大型工程中安全地引入 LTO，使跨模块调用的开销降到最低，同时有效控制二进制文件的体积。
