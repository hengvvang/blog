# 前言：GCC 编译优化与底层汇编的艺术

在现代软件工程与系统级开发中，编译器不仅是将高级语言翻译为机器码的工具，更是底层性能优化的核心引擎。尤其是对于嵌入式系统、操作系统内核、高频交易系统以及底层驱动等对性能与二进制体积有极端要求的场景，深入理解编译器的优化机制，掌握与编译器直接对话的**内联汇编（Inline Assembly）**与**链接时优化（LTO）**技术，是每一位高级系统级工程师的必修课。

本手册旨在从**原理剖析、汇编对比、优化调优、工程实践**四个维度，全面拆解 GCC（GNU Compiler Collection）在编译优化及汇编层面的深层运作机制。

### 第一部分：编译器优化级别与链接期优化
这一部分重点解析在单个编译单元及跨编译单元（全局）下，编译器是如何理解并优化代码的。
* **[优化级别与 LTO](optimization/README.md)**：简述 GCC 编译优化流水线（GENERIC -> GIMPLE -> RTL -> 汇编）以及高级优化的核心概念。
* **[第一章：GCC 优化级别深度剖析与性能评测](optimization/optimization-levels.md)**：对比分析 `-O0`、`-O1`、`-O2`、`-O3`、`-Os`、`-Oz`、`-Og` 和 `-Ofast` 各自的优化侧重点与底层机制，并深入探讨常量折叠、死代码消除、公共子表达式消除的汇编对比；进一步解密循环展开、循环剥离以及自动向量化（SIMD）的底层触发条件与汇编行为。
* **[第二章：内联函数与链接期优化 (LTO) 原理](optimization/inline-and-link-optimization.md)**：探讨编译器如何计算函数内联的代价（Inline Cost）、如何通过 `always_inline`、`noinline`、`noipa` 以及空 asm volatile 屏障实现对编译器的精准控制；详细拆解 LTO（链接时优化）在全局调用图（Call Graph）分析、全程序死代码消除（WPA）与分区代码生成（LTRANS）上的工作原理，并提供规避 LTO 负面效应（如符号非预期丢失、调试信息降级等）的生产级解决方案。

### 第二部分：内联汇编
这一部分教导读者如何绕过编译器的指令生成限制，直接在 C 语言代码里嵌入安全、无副作用的硬件架构指令。
* **[GNU 内联汇编](assembly/README.md)**：介绍 GNU 内联汇编基本语法、扩展四段式语法结构与编译器寄存器分配器的基本关系。
* **[第三章：GNU 内联汇编语法与嵌入式开发实战](assembly/inline-assembly.md)**：深度剖析扩展内联汇编的四段式语法；对各种寄存器与内存约束（`r`、`m`、`i`、`g` 等）和约束修饰符（`=`、`+`、`&`）进行详实讲解；分析 Earlyclobber（早期擦除）冲突机制并绘制其寄存器分配对照图；提供 ARM Cortex-M 和 x86_64 双架构下，关于临界区开关中断、无锁原子自增（LDREX/STREX）、精确时间戳读取（RDTSC）以及高速内存填充（`rep stosq`）的生产级代码样例与全面注释。

## 学习本手册的收获

完成本书的学习后，您将能够：
1. **洞悉机器指令**：面对复杂的 C 语言控制流与数据流，能够准确预测 GCC 会将其翻译成何种形态的物理汇编指令。
2. **掌控系统性能**：不再盲目选择 `-O3`，而是能根据具体的 CPU 微架构（如 L1 I-Cache 容量、流水线气泡）和业务特点定制最优的编译选项组合。
3. **编写安全汇编**：掌握 Earlyclobber 和 Clobber List 的核心精髓，写出无副作用、寄存器分配精确、绝不破坏编译器优化上下文的高性能内联汇编代码。
4. **实践全局调优**：在大型软件工程中安全地引入 LTO 技术，在跨编译单元消除多余开销的同时，有效控制二进制文件的物理大小，并防止关键的中断服务程序或底层符号被编译器非预期剔除。
