# CMake 语法与变量基础

本部分深入探讨 CMake 的基本语法、变量系统的运作机制以及核心控制结构。作为 C/C++ 项目的事实标准构建工具，CMake 本身不仅是一门声明式的目标依赖管理语言，更拥有一套完整的脚本语言（Scripting Language）体系。理解这一套体系是编写高效、高可维护性构建脚本的关键。

## 1. CMake 脚本语法基础

CMake 的解析器是基于命令（Command）驱动的。每一个 `CMakeLists.txt` 文件在本质上都是一系列按顺序执行的命令流。
- **命令调用**：格式为 `command_name(arg1 arg2 ...)`。命令名不区分大小写，但业界目前推荐统一使用小写，如 `set()`、`project()`、`add_executable()`。
- **变量引用**：格式为 `${VAR_NAME}`。变量名区分大小写。
- **参数解析**：CMake 命令的参数可以通过空格或换行符分隔。如果参数中包含空格，必须使用双引号包裹，否则会被解析为多个独立的参数。
- **字符串与列表**：在 CMake 中，所有变量的值在底层都可以视作字符串。而列表（List）在底层则是通过分号 `;` 分隔的字符串。例如，`a;b;c` 就是一个包含三个元素的列表。

## 2. 变量体系：局部变量 vs 缓存变量 vs 环境变量

CMake 提供了三种不同类型的变量，其设计初衷是为构建生命周期的不同层面提供状态存储与跨模块参数传递：

```text
+-----------------------------------------------------------+
|                      操作系统环境变量                     |
|                   (ENV{VAR}, 随进程销毁)                  |
+-----------------------------------------------------------+
                              | 继承/读取
                              v
+-----------------------------------------------------------+
|                      CMake 缓存变量                       |
|           (CACHE, 持久化于 CMakeCache.txt 中)             |
+-----------------------------------------------------------+
                              | 继承/读取/重写
                              v
+-----------------------------------------------------------+
|                      CMake 局部变量                       |
|             (Normal, 存在于内存堆栈，写时复制)            |
+-----------------------------------------------------------+
```

### 局部变量 (Normal Variables)
- **定义**：`set(VAR_NAME "value")`。
- **作用域**：局限于当前的 `CMakeLists.txt` 文件目录（及其通过 `add_subdirectory` 引入的子目录）或当前函数（`function`）内部。
- **传播特性**：
  - 子目录会继承父目录中已定义的局部变量拷贝。
  - 子目录对变量的修改不会回传给父目录（典型的 Copy-On-Write 机制）。
  - 函数内部定义的变量为局部变量，若要回传需使用 `PARENT_SCOPE` 关键字。

### 缓存变量 (Cache Variables)
- **定义**：`set(VAR_NAME "value" CACHE TYPE "docstring" [FORCE])`。
- **物理载体**：存储在构建目录下的 `CMakeCache.txt` 中。
- **生命周期**：全局持久化。一旦被写入，即使在 CMake 脚本中多次重新运行配置，也不会覆盖已有值，除非在命令行使用 `-D` 显式更改或在代码中加上 `FORCE` 关键字。
- **作用**：提供给开发者配置构建选项（如 `-DCMAKE_BUILD_TYPE=Release`）。

### 环境变量 (Environment Variables)
- **定义/读取**：`set(ENV{VAR_NAME} "value")` / `$ENV{VAR_NAME}`。
- **生命周期**：仅在当前 CMake 进程及子进程内有效，不持久化于 `CMakeCache.txt` 中。

## 3. 核心命令概述

本部分包含以下核心构建命令与语法的应用：
- `set()`：定义局部/缓存变量。
- `option()`：提供布尔类型的缓存选项开关。
- `message()`：输出构建时诊断信息。
- `add_subdirectory()`：向构建系统添加子目录，开辟新的目录作用域并传递变量。
