# Python 基础装饰器与闭包

在 Python 编程语言中，**装饰器 (Decorators)** 是一项极其优雅且功能强大的特性。它允许我们在不修改函数或类本身的前提下，动态地为其添加功能。无论是 Web 框架（如 Flask/FastAPI 中的路由分发）、ORM 框架（如 SQLAlchemy 的属性映射），还是日常开发中的日志记录、耗时统计、权限控制、缓存（如 `lru_cache`），装饰器都扮演着至关重要的角色。

然而，要彻底掌握装饰器，不能仅仅停留在使用 `@` 语法糖的表面，而是需要从底层的**词法作用域 (Lexical Scope)** 和**闭包 (Closures)** 机制出发，深入探究 Python 虚拟机如何处理变量的生命周期，以及如何在运行时进行函数的包装与重构。

---

## 🎯 学习目标

通过阅读本书，你将掌握以下核心内容：

1. **彻底剖析闭包的内存模型**  
   了解 Python 的 `LEGB` 变量查找规则，深入探讨 `nonlocal` 的底层行为，分析 Python 在编译期与运行期是如何通过 `cell` 对象与 `__closure__` 属性实现闭包的。
   
2. **掌握装饰器的本质与标准语法**  
   解密 `@` 语法糖背后的本质，理解装饰器在编译阶段的求值行为，掌握如何设计通用的参数代理 (`*args`, `**kwargs`)，并学会使用 `functools.wraps` 恢复被包装函数丢失的元数据（如 `__name__`、`__doc__` 等）。

3. **落地高可用的实用装饰器**  
   亲手实现生产级别的性能监控（高精度耗时统计）、系统级调试日志记录以及线程安全的单例模式。

---

## 📂 章节大纲

本书由浅入深，分为以下三个主要章节：

### 1. [闭包与作用域原理](01_closure_fundamentals.md)
介绍局部作用域、全局作用域与嵌套作用域。以第一类对象（First-Class Citizens）为基础，分析闭包的本质，并使用 Mermaid 图形化展示闭包在内存中的引用关系以及自由变量的生命周期延长机制。

### 2. [基础装饰器语法与 @ 符号](02_basic_decorator_syntax.md)
剖析装饰器的定义与演变。手动推导不带语法糖的装饰器形式，进而引入 `@` 语法。详细讨论参数的通用代理，以及为什么必须要使用 `functools.wraps` 来还原元数据。

### 3. [实用装饰器案例实战](03_practical_decorators.md)
通过三个具有代表性的工程实践案例，将理论转化为实际生产力。每个案例都包含完整的、带注释的 Python 代码，并附有设计思路和详细的输出结果解析。
