# Python 基础装饰器与闭包

在 Python 编程世界中，**装饰器 (Decorators)** 是一项极其优雅且功能强大的元编程特性。它允许我们在不修改函数或类定义的前提下，动态地为其注入、修改或扩展行为。无论是在主流的 Web 框架（如 Flask 的路由定义、FastAPI 的依赖注入）、ORM 系统（如 SQLAlchemy 的状态映射与跟踪），还是日常的业务开发（如日志记录、接口耗时统计、身份权限拦截、分布式限流）中，装饰器都扮演着底层的支柱角色。

然而，要彻底掌握装饰器，不能仅停留在 `@` 语法糖的黑盒使用层面，而需要更进一步，从底层的**词法作用域 (Lexical Scoping)**、**LEGB 命名空间检索规则**，以及 CPython 解释器处理变量生命周期的**闭包内存机制**出发，理解其完整的底层运行脉络。

---

## 🎯 本书学习目标

通过阅读本书，你将从底层到工程实践，全面掌握以下核心知识：

1. **彻底剖析闭包的内存模型与虚拟机行为**  
   探讨 Python 解释器在编译期与运行期对变量符号的解析策略，深入剖析 `PyCellObject` 细胞变量的工作机制，理解为什么即使外层函数执行完毕退栈，闭包中的自由变量生命周期依然能够得以延续。
   
2. **掌握装饰器的本质与标准设计模式**  
   拆解 `@` 语法糖在解释器底层的求值绑定逻辑，掌握如何使用 `*args` 和 `**kwargs` 实现万能参数的透明转发，以及如何通过 `functools.wraps` 恢复被包装函数丢失的元数据，确保调试堆栈的准确。

3. **落地高可用的生产级装饰器案例**  
   通过高精度性能耗时统计器、交易审计日志拦截器、多线程安全的双重锁单例模式，以及基于线程本地存储上下文的权限拦截门控，全面提升面向切面编程（AOP）的代码设计能力。
