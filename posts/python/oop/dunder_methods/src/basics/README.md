# 对象创建、初始化与操作基础

在本部分中，我们将深入探讨 Python 数据模型（Data Model）中最基石的组成部分：**对象的构建生命周期管理**与**运算符重载机制**。

Python 的“协议式编程”哲学在这一部分得到了最集中的体现。通过实现特定的双下划线魔术方法（Dunder Methods），自定义的类可以无缝地融入 Python 的内置语法体系，使其行为与内置的 `list`、`dict`、`float` 等原生类型无异。

---

## 本部分核心主题

### 1. 类实例化路由与对象生命周期
在 Python 中，创建一个新实例绝非仅仅调用 `__init__` 那么简单。本部分将详细解剖 CPython 解释器在执行 `obj = MyClass()` 时的底层步骤：
* **内存分配与构建 (`__new__`)**：作为类级别的静态工厂方法，`__new__` 负责在堆内存上为新对象申请空间，并返回未初始化的实例。它是拦截对象创建、实现单例模式以及定制不可变子类（如继承 `str`、`tuple`）的唯一入口。
* **状态初始化 (`__init__`)**：在实例创建完毕后被调用，用于绑定属性和初始化状态。
* **对象生命终点与垃圾回收**：探讨析构方法 `__del__` 的隐患、垃圾回收（引用计数与分代 GC）下的调用不确定性，并给出替代资源释放方案。

### 2. 对象表现力与序列化机制
当我们将对象打印到终端、记录日志、写入文件或进行网络传输时，需要将其转换为对应的文本或二进制流。我们将学习以下机制：
* **`__repr__` 与 `__str__`**：区分面向开发者调试与面向最终用户的不同字符串表现形式，遵循 `eval(repr(obj)) == obj` 的最佳实践。
* **`__format__`**：基于 f-string 与内置 `format()` 函数，实现类内部的微型语法解析器（如格式化经纬度、日期等）。
* **`__bytes__` 与二进制打包**：结合 `struct` 模块，将对象状态紧凑地序列化为二进制字节流。

### 3. 运算符重载与全关系序排列
Python 将加、减、乘、除、比较等运算符映射到了一系列的魔术方法上。
* **富比较（Rich Comparisons）**：通过实现 `__lt__`、`__eq__` 等方法，并结合 `@functools.total_ordering` 装饰器，为自定义对象提供完整的大小比较与排序能力。
* **反射与就地运算**：深入理解当左操作数不支持时，Python 如何查找右侧反射方法（如 `__radd__`），以及在处理可变对象与不可变对象时，就地运算符（如 `__iadd__` 的 `+=`）在内存管理上的设计差异。

## 知识脉络图

```
                +-----------------------+
                |   MyClass(*args)      |
                +-----------+-----------+
                            |
                            v
               +------------+------------+
               |  __new__(cls) 内存分配   |
               +------------+------------+
                            |
                            v (返回新实例)
               +------------+------------+
               | __init__(self) 状态初始化|
               +------------+------------+
                            |
         +------------------+------------------+
         |                                     |
         v                                     v
+--------+--------+                  +---------+---------+
|    对象表示法    |                  |    运算符重载     |
| - __str__       |                  | - 算术: __add__   |
| - __repr__      |                  | - 反射: __radd__  |
| - __format__    |                  | - 就地: __iadd__  |
| - __bytes__     |                  | - 比较: __lt__等  |
+-----------------+                  +-------------------+
```

通过这一部分的学习，你将不仅掌握如何使用这些方法，更将理解它们在 CPython 虚拟机中的底层查找优化（类型插槽，Type Slots），从而能够设计出兼顾语义优雅与执行效率的高质量 Python 类。
