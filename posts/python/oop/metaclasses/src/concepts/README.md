# 第一部分：类构建原理与 dynamic 创建

欢迎来到本书的第一部分。在这一部分中，我们将重点探索 Python 核心对象模型中最基础也最深刻的部分：**类的定义与构建原理**。

## 本部分核心主题

1. **类实例化生命周期 (Class Instantiation Lifecycle)**
   在 Python 中，不仅实例的创建有其特定的生命周期（由 `__new__` 和 `__init__` 控制），类本身的创建同样也是一个完整的对象实例化过程。理解“类也是对象”是通往元编程大门的钥匙。

2. **`type` 元类 (The type Metaclass)**
   我们将深度剖析内置对象 `type` 的双重角色：作为普通的类型查询函数，以及作为创造所有类对象的“元类（Metaclass）”。我们将解构 `type` 如何打破“鸡生蛋、蛋生鸡”的无限循环，确立 Python 优雅的对象拓扑关系。

3. **动态子类与动态类定义 (Dynamic Subclass Definitions)**
   掌握不通过 `class` 关键字，而直接使用 `type(name, bases, attrs)` 在运行时动态组装类、添加属性、绑定父类并派生子类的技巧。这在处理动态配置、反序列化生成类、以及动态 RPC 客户端代理时具有不可替代的作用。

## 知识框架概览

在进入第一章前，让我们先建立一个基本的概念图景：

```
+-------------------------------------------------------------+
|                     Python 运行时环境                        |
+-------------------------------------------------------------+
                               |
            遇到 class MyClass(Base): 声明或调用 type()
                               |
                               v
                  [1. 确定元类 (Metaclass)]
                               |
                               v
                [2. 收集命名空间 (Namespace)]
                               |
                               v
             [3. 调用元类实例化 (Metaclass __new__)]
                               |
                               v
                     [4. 得到类对象 (MyClass)]
```

通过本部分的学习，你将揭开 `class` 关键字的神秘面纱，直击 Python 虚拟机的类编译与构建底层。
