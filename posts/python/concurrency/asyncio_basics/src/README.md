# 前言

在高并发、高吞吐量的现代互联网应用中，I/O 密集型任务（如网络请求、数据库查询、磁盘读写等）是系统性能的核心瓶颈。传统的应对方案包括多进程模型和多线程模型：
- **多进程模型**：依靠操作系统内核进行进程切换。每个进程拥有独立的内存空间，虽然相互隔离、安全性高，但进程创建、销毁及上下文切换的内存和 CPU 开销极大。
- **多线程模型**：在同一个进程内创建多个线程。虽然共享内存降低了开销，但由于 Python 的全局解释器锁（GIL，Global Interpreter Lock）的存在，多个线程无法真正利用多核 CPU 进行并行计算。此外，成千上万个线程的上下文切换（寄存器状态保存、栈空间分配、内核调度）依然会带来巨大的延迟与内存开销。

为了解决这一痛点，**异步非阻塞 I/O（Async I/O）** 与 **协程（Coroutine）** 机制应运而生。Python 3.4 引入了 `asyncio` 标准库，并在 Python 3.5 中正式支持 `async/await` 原生协程语法。

`asyncio` 采用**单线程事件循环（Event Loop）**模型，通过协同式多任务调度（Cooperative Multitasking），让单个线程能够以极低的内存开销驱动成千上万个并发网络连接，从而极大提升了 I/O 密集型应用的并发性能。

## 本书设计与知识体系

本书旨在由浅入深地剖析 Python 异步编程的底层机理、标准库 API 的设计原则、以及生产环境下的高性能并发模式。全书分为以下三个核心章节：

### 1. 从 Generator 到 Native Coroutine 与事件循环底层机制
我们将回溯 Python 异步编程的历史演进，解释生成器（Generator）如何通过 `yield`、`send()` 和 `yield from` 实现协同式上下文切换。接着，我们将剖析原生协程（`async def`）在编译期的本质属性（`CO_COROUTINE` 标志），并深入事件循环（Event Loop）的核心架构，探索底层的 `selectors` 模块与操作系统多路复用系统调用（如 `epoll`、`kqueue`、`IOCP`）。在本章的最后，我们将手动编写一个基于非阻塞 Socket 的极简事件循环，帮助读者彻底打通“协程 -> 事件循环 -> 操作系统”的闭环。

### 2. asyncio 核心 API 详解与任务调度
本章将从概念和源码层面理清 `Coroutine`（协程对象）、`Future`（未来对象）与 `Task`（任务）的三角关系，并展示它们在事件循环中的状态跃迁。随后，我们将详尽解析 `asyncio` 的核心 API，包括启动入口 `asyncio.run()` 的生命周期、任务的创建与取消机制（`asyncio.create_task`、`CancelledError`、`asyncio.shield`）、以及三大并发组合器（`gather`、`wait`、`as_completed`）的使用场景和底层异常控制机制逻辑。

### 3. 高并发模式与线程/进程执行器集成
在实际开发中，不可能所有第三方库都提供了异步接口。如何避免同步阻塞代码（例如 `requests` 库或同步数据库驱动）卡死单线程事件循环？我们将深度讲解 `loop.run_in_executor()` 与 `ThreadPoolExecutor`/`ProcessPoolExecutor` 的集成方式。接着，我们将介绍异步特有的并发控制与同步原语（如 `Semaphore`、`Queue`、`Lock`）以及异步上下文管理器（`async with`）。最后，我们将提供一个可直接用于生产的高并发异步 TCP 服务端实战案例，包含粘包处理与长连接心跳管理。

## 学习目标

完成本书的学习后，您将能够：
1. **洞悉底层**：清晰阐述 Python 协程从生成器演进到 `async/await` 的底层逻辑，并理解事件循环的多路复用原理。
2. **驾驭 API**：熟练运用 `asyncio` 的各种核心 API，设计鲁棒的任务生命周期管理方案，正确捕获并处理异步链路中的异常。
3. **混合编程**：安全地在异步应用中混用同步阻塞库与 CPU 密集型算法，确保事件循环的高效流转。
4. **规避陷阱**：掌握防止事件循环阻塞（Blocking Event Loop）的调试与监控手段，编写符合生产规范的高性能异步程序。
